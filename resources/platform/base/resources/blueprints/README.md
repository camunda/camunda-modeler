# Blueprints Directory

Each directory is a blueprint. The Camunda Modeler copies its files into a project folder you choose.

To change a blueprint, store a directory with the same name in the `resources/blueprints` directory in the modeler's data directory.

## AI Agent Chat Quick Start

`ai-agent-chat-with-tools` is copied from [camunda-8-tutorials](https://github.com/camunda/camunda-8-tutorials/tree/f45900306d3d1b7440252646849557083eb062b7/solutions/ai-agent-chat-with-tools) and prepared for Self-Managed: the AI Agent has no LLM endpoint, model and authentication, as the Camunda-provided LLM exists on SaaS only.
